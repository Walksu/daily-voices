一天一篇，新的写在最上面。只留值得留下来的，同一天同一个链接只出现一次。

One file a day, newest first. Only what is worth keeping. The same link appears once on a given day.

## 关于 · About

访谈、播客，以及本人开口的长文和视频。

Interviews, podcasts, and long pieces or videos where the person speaks for themselves.

## 一条里有什么 · What one entry holds

| 字段 Field | 写什么 |
| --- | --- |
| 日期 Date | `YYYY-MM-DD` |
| 标题 Title | 原文标题，必要时补一句中文 |
| 链接 Link | 原文地址 |
| 为什么留 Why | 一句，说清它为什么在这本里 |

正文在 [entries](entries)。空页是 [entries/_template.md](entries/_template.md)。

## 不收 · Left out

名单里的人自己写的博客去 daily-essays。机构新闻、转述和财经引语不进这本。

Blogs written by people on the list go to daily-essays. Institutional news, retellings, and quoted market lines stay out.
